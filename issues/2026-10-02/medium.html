Claude Code mods: plugins із файлом входу з кодом

Що з'явилося

Mods — це plugins для Claude Code з модулем hooks на JavaScript або TypeScript, який Claude Code викликає при подіях. Claude може написати його за описом, або ви пишете його самі. Потрібна версія v2.1.287 або новіша.

Чому це важливо

Hooks і skills були конфігурацією або промптами. Mod — це справжній код, який може рахувати виклики інструментів і додавати команди без Node.js, бандлера чи етапу збирання. Він перезавантажується наприкінці кожного ходу.

Як використати

Виконайте claude --version і переконайтеся, що версія v2.1.287 або новіша. Попросіть створити mod у сесії або завантажте /plugin-authoring. Схваліть гаряче перезавантаження для сесії, потім перевірте /plugin на вкладці Installed. Скопіюйте каталог із ~/.claude/dev-mods/, щоб зберегти його, і завантажте через claude --plugin-dir. Запустіть claude plugin validate.

Projects: одна розмова координує паралельні хмарні сесії

Що з'явилося

Projects, у публічній бета-версії для Pro і Max, дають змогу одній розмові запускати хмарний потік для кожного завдання. Потоки спільно використовують репозиторії, інструкції та пам'ять. Панель Overview показує, що завершено і що чекає на вас.

Чому це важливо

Раніше запуск кількох сесій означав, що ви самі розподіляли роботу, повторювали контекст і перевіряли кожну сесію. Project зберігає постійні правила в одному місці й перекладає цю координацію на Claude.

Як використати

Шукайте Projects на бічній панелі на вкладці Code у вебзастосунку або застосунку для комп'ютера. Якщо його немає, приєднайтеся до списку очікування. Почніть із цілі, що охоплює кілька репозиторіїв, і один раз задайте правила, як-от цільову гілку. Стежте за використанням плану: projects витрачають ті самі ліміти, але швидше.

Додано URL-запити MCP; деяким серверам може знадобитися прапорець конфігурації

Що з'явилося

Claude Code тепер підтримує URL-запити від MCP servers за протоколом 2025-11-25, наприклад для входу в обліковий запис. Якщо сервер перестав підключатися після оновлення, додайте "bareElicitationCapability": true до його запису в конфігурації MCP.

Чому це важливо

Сервери можуть спрямовувати користувачів на сторінку входу, тож для потоків автентифікації більше не потрібні обхідні рішення. Оновлення також може порушити підключення, тому авторам MCP server варто це перевірити.

Як використати

Після оновлення перепідключіть усі MCP servers, якими користуєтеся. Якщо якийсь не підключається, додайте "bareElicitationCapability": true до запису цього сервера в конфігурації MCP. Протестуйте URL-запити у власних серверах.

Copilot CLI отримує computer use для настільних програм

Що з'явилося

Computer use перебуває в публічному превʼю в Copilot CLI та застосунку Copilot на macOS і Windows. Copilot може клікати, вводити текст, прокручувати й перетягувати в настільних програмах, запитуючи дозвіл перед керуванням програмою.

Чому це важливо

Це дає доступ до програм лише з графічним інтерфейсом і застарілого ПЗ без API, CLI чи інтеграції MCP, які термінальні агенти раніше не могли автоматизувати.

Як використати

У Copilot CLI виконайте /computer on, перевірте через /computer show, вимкніть через /computer off. На macOS надайте дозволи Accessibility і Screen Recording, крок за кроком він вас проведе. Опишіть результат, програми та обмеження.

Урок тижня

Створіть крихітний mod для Claude Code з циклом перезавантаження

Mod — це plugin, файлом входу якого є модуль JavaScript або TypeScript. Claude Code викликає його функції, коли відбуваються події, тож це код, а не промпт чи статична команда hook. Claude Code завантажує .js і .ts безпосередньо, без етапу збирання. Робочий цикл складається з трьох частин. Спочатку напишіть: попросіть Claude створити чернетку mod, для чого використовується вбудований skill plugin-authoring, або напишіть його самі. Далі перезавантажте: після того як ви схвалите гаряче перезавантаження для сесії, зміни завантажуються наприкінці кожного ходу. Потім перевірте: запустіть claude plugin validate і прочитайте оголошення типів, які Claude Code записує поруч із mod, щоб побачити, які події та методи доступні у вашій версії. Обирайте mod, коли потрібна логіка, наприклад підрахунок, форматування або нова команда. Віддавайте перевагу простому skill або налаштуванню, коли досить текстових інструкцій. У документації є порівняння mods, налаштувань, hooks, skills і MCP servers; прочитайте його перед вибором. Mod, який пише Claude, лежить у теці сесії, яку згодом очищають. Скопіюйте його в постійний каталог, щоб зберегти.

Вправа на 15 хвилин

Переконайтеся, що claude --version показує v2.1.287 або новішу. Попросіть Claude: створити модифікацію, яка рахує виклики інструментів і додає команду /tally. Підтвердьте гаряче перезавантаження, перевірте його через /plugin, виконайте кілька викликів інструментів, потім попросіть про одну зміну й простежте, як вона перезавантажиться. Наприкінці виконайте claude plugin validate.
