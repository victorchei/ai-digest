Тенденції тижня

Claude Code розвивається у бік спостережуваності та програмованості: span-и OpenTelemetry тепер відповідають конвенціям GenAI, записи про рішення щодо інструментів фіксують, хто ухвалив рішення — класифікатор auto mode чи правило, а mods отримують hooks для промптів і workflow-агентів. Для автономних запусків з'являються запобіжники, наприклад обмеження часу очікування скидання ліміту використання в режимі повторних спроб. Конкуруючі інструменти рухаються в тому самому напрямку: Codex додає коригування посеред ходу та паралельні інструменти лише для читання, а Copilot розширюється на чат-застосунки з підтримкою кількох репозиторіїв.
